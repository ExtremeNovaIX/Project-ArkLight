# Gamer Runtime TODO

## 多人实时语音打断边界

- 使用正则词表对 partial 识别文本做轻量门控，不再调用旧路由器或 LLM 做高频意图判断。
- 当用户语音包含紧急战术、纠错、停止、目标变更等意图时，先让游戏执行进入 voice hold，再等待完整语义闭合。
- 声学侧需要先区分正常人声、噪声、重叠说话和异常频段，避免把非人声送入语义链路。
- 中断请求需要有明确消费边界，避免一次用户指令在后续 tick 中反复触发。
- 多人同时发言时需要仲裁规则，至少区分队友闲聊、战术讨论、强制停止和直接控制指令。
- 打断策略应优先服务回合制和低反应力游戏，不把高频动作游戏作为第一版目标。
